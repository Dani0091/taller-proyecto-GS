# TallerAgil - Sistema de Gestión para Talleres

**Proyecto Intermodular 1ºGS DAM**  
**Alumno:** Daniel Almaquio  

## Descripción

Aplicación web para gestión de talleres mecánicos pequeños.

## Tecnologías

- Next.js 14
- TypeScript
- TailwindCSS
- Supabase

## Instalación
```bash
npm install
cp .env.example .env.local
npm run dev
```
